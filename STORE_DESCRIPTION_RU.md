# Описание для Chrome Web Store (Русский)

## Краткое описание (132 символа максимум)

Добавляет выделенные слова в словарь карточек на kotcat.com простым правым кликом.

## Полное описание

### KotCat – Сохраняй слова во время чтения

**Установить:** [Chrome Web Store](https://chromewebstore.google.com/detail/kotcat-%E2%80%93-save-words-while/hbjmiobfalkndjepaclgglgfjkfnegim)

**Легко пополняйте свой словарный запас с KotCat!**

Помощник словаря карточек — это мощное расширение Chrome, которое позволяет легко добавлять слова в ваш словарь карточек на kotcat.com. Просто выделите любое слово на любой веб-странице, нажмите правую кнопку мыши и добавьте его в словарь одним кликом.

### Основные возможности

✨ **Добавление слов одним кликом**
- Выделите любое слово или фразу на любой веб-странице
- Нажмите правую кнопку мыши и выберите "Добавить в словарь"
- Слово мгновенно сохраняется в вашу папку карточек на kotcat.com

🌍 **Поддержка нескольких языков**
- Полностью локализованный интерфейс на 7 языках:
  - Английский
  - Русский
  - Испанский
  - Португальский
  - Французский
  - Немецкий
  - Китайский
- Автоматически определяет язык вашего браузера

⚙️ **Простая настройка**
- Настройте ваш API-токен на kotcat.com/profile
- Выберите целевую папку
- Включайте/выключайте расширение в любое время

🔒 **Конфиденциальность**
- Все настройки хранятся локально на вашем устройстве
- Никакого сбора данных сверх необходимого
- Безопасная HTTPS-связь с kotcat.com

📱 **Умное контекстное меню**
- Видите выделенное слово в контекстном меню
- Быстрый доступ с любой веб-страницы
- Визуальное подтверждение при добавлении слов

### Как это работает

1. **Получите ваш API-токен**
   - Посетите kotcat.com/profile
   - Создайте API-токен
   - Скопируйте его в настройки расширения

2. **Выберите вашу папку**
   - Расширение загружает ваши доступные папки
   - Выберите, куда сохранять новые слова

3. **Начните учиться**
   - Просматривайте любые веб-сайты
   - Выделите слово, которое хотите выучить
   - Правый клик → "Добавить в словарь"
   - Готово! Слово сохранено с URL источника

### Идеально для

- Изучающих языки, пополняющих словарный запас
- Студентов, собирающих новые термины
- Исследователей, сохраняющих важные слова
- Всех, кто использует kotcat.com для обучения на карточках

### Конфиденциальность и безопасность

- Ваш API-токен хранится безопасно на вашем устройстве
- Только выделенные слова и URL источников отправляются на kotcat.com
- История просмотров или личные данные не собираются
- Полный контроль над вашими данными

### Требования

- Аккаунт на kotcat.com
- API-токен с kotcat.com/profile
- Хотя бы одна папка в вашем аккаунте kotcat.com

Нужна помощь? Посетите kotcat.com или свяжитесь с нами через страницу поддержки Chrome Web Store.
